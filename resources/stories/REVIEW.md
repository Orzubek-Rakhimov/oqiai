## Syllables

Every word was loaded and its automatic split was checked. **No syllable overrides were added.** No word in these Stories needed one under the convention the rule uses:

- **ng counts as one letter** when it stands for one sound, so a single ng between vowels moves to the next syllable: `ya-ngi`, `u-ning`, `me-ning`, `ra-ngi`, `u-nga`. This follows the school rule as I understand it ("ko'-ngil", "si-ngil"). **Please confirm.** If you prefer `yan-gi`, `ran-gi` and so on, each of those words needs an override line. No word with ng as two sounds (n + g, like `den-giz`) is used.
- Splits that are worth checking:
  - `do's-ti`, `sinf-dosh-la-rim`, `da-raxt-lar`: only the last consonant of a cluster moves.
  - `o-i-la`, `vo-qe-a-lar-ni`: vowels next to each other.
  - `ta'-til`, `va'-da`, `ta'-mir-la-shar-di`: the tutuq belgisi stays with the syllable before it.
  - `bo-g'i`, `ir-g'a-di`, `uy-g'o-nib`, `qich-qi-ri-g'i-dan`: g' as one letter.

  - `ta'mirlashardi` ("were repairing [the nest]"): is this a natural word for a nest?
